# fullstacktics

Static one-page site for Fullstacktics, an SEO, PPC, web development and design agency. It is the landing page for outbound audit emails from `../ads_audit`, so the client work sits right after the hero.

Content spec lives in [JOURNEY.md](JOURNEY.md); the visual tokens are the `:root` block in `styles.css`.
